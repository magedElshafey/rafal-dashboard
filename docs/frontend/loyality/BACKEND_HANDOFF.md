Confirmed product behavior: effective returns strictly above 10% show a localized, non-blocking warning. The warning is calculated locally, adds no request field, and does not require confirmation.

The existing Laravel validation envelope is sufficient and is already reused; a new generic error contract is not requested.

Authorization is backend-owned. The frontend intentionally adds no RBAC, capability hooks, or control-visibility rules and relies on the existing standard 401/403 handling.
